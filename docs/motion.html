Accessibility

Reduced motion

Every utility above stops animating under prefers-reduced-motion: reduce — loops freeze at their rest state, entrances show the final frame, and scroll-driven classes simply don't run. The Reveal component's hidden state only applies after JavaScript adds html.js, so content is never invisible with scripting off.
