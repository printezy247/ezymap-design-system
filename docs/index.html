What's new

  • Macro Fundamentals glyph: the gem is replaced by a fundamental-trading glyph (candlestick cluster + rising macro line). New variations: gold, white, black. See the base mark and the bottom logo area.
  • Apple-inspired motion growth: spring pops and blur entrances, particle bursts, orbit dots, a rotating cube, 3D marker orbits and a pulsing brand glow (CardStack, CursorSpotlight). New products `crypto` + `forex` from trading research. More at the motion playground.
  • Apple-inspired language: 8px and 10px button corners, larger section gaps (56/96px), cards at 16–24px, display heads at weight 400–500 with −0.022em tracking, nearer-black foreground on light mode.
  • Four new components (16 total): LiveBadge (live status pill with ping ring), Marquee (seamless scroll strip with direction/duration controls), Skeleton (shimmer loading placeholder) and GlowCard (card with breathing glow or rotating border beam) — in React, vanilla bundle and typings.
  • Spring motion tokens: ease-spring-snappy and ease-spring-gentle join ease-spring — cubic-bezier approximations of Motion-style springs for CSS-only consumers.
  • Agent ergonomics: docs/llms.txt + docs/llms-full.txt (LLM-readable system reference), docs/motion.html (live motion playground), scripts/manifest.mjs (asset resolver CLI, also npm run manifest) and mcp/server.mjs (zero-dependency MCP server exposing tokens, components, motion and assets to AI agents).
  • Install snippets: every component README now opens with a copy-paste React + vanilla install block.
  • 3D pipeline decision (docs/3d-pipeline-decision.md): SVG/PNG stays canonical; Spline/Rive documented as the revisit path for real-time 3D.
  • Accessibility section below documents reduced-motion, no-script and focus behaviour.
  • Marquee tracks now honour --marquee-duration and .ezm-marquee--always.

Accessibility

Built to be usable by everyone

  • Reduced motion. Every animation in the six motion stylesheets stops under prefers-reduced-motion: reduce — loops freeze at rest, entrances show the final frame, scroll-driven classes don't run. Try it: enable "reduce motion" in your OS accessibility settings and reload this page.
  • No JavaScript. Content is never hidden without scripting. The Reveal component's hidden state only applies after mount adds html.js; scroll-driven motion is gated behind @supports (animation-timeline) and no-preference.
  • Keyboard. All interactive elements show a 2px accent focus ring offset from the background; product tiles, flip cards and depth cards are focusable and respond to :focus-visible.
  • Colour. Text pairs are AA-checked per surface (see token usage notes); up/down market states always pair colour with a sign or arrow, and the only red is SignalFlag "Stopped".
  • Images. ProductIcon and EzyMapLogo ship sensible default alt text; decorative marks use aria-hidden. Marquee strips pause on hover and focus.

Live demos of every motion utility, including the reduced-motion behaviour, are on the motion playground.
