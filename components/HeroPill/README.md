# HeroPill

A dark bevelled pill with a green hairline that sits above the hero headline and carries one live figure and a label.

- **Use** once, above the h1, for example "640 Active Members · Est. 2021". The figure should be live data (the Telegram member count).
- **Consumer supplies:** `icon` (a 14px Lucide icon, tinted `primary`), `value` (mono, `primary`, tabular numerals) and the label as children. The label is uppercased by the style, so type it in normal case.
- **Don't** stack several pills or use one as a button.
