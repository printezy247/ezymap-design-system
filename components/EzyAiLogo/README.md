# EzyAiLogo

The EzyAI product mark is a gold isometric cube on a deep-green disc, drawn as a vector so it stays crisp from a 14px chip to a 160px watermark.

- **Use** only for the EzyAI signal and autopilot product. The parent brand uses the EzyMap mark (see Logos).
- **Consumer supplies:** a size via `className` or `style`, and `title` when no "EzyAI" text sits beside it.
- **`withWordmark`** adds "EzyAI" (white "Ezy", gold "AI") below the cube. Use it only at 64px or larger. Without it, the cube re-centres on the disc.
- **Don't** recolour, flatten or outline the mark.
